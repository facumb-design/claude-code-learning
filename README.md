# Claude Code Lab

Este repositorio es un **laboratorio de aprendizaje** para practicar con Claude Code.

## Objetivo

Usar este espacio para aprender y experimentar con:

- **Agentes**: Cómo crear y usar agentes especializados
- **MCP (Model Context Protocol)**: Integración con servidores MCP
- **Instrucciones y Prompts**: Mejores prácticas para comunicarse con Claude Code

## Propósito

Practicar buenas prácticas de:
- Código limpio y mantenible
- Automatización de tareas
- Desarrollo con IA como copiloto
