# CLAUDE.md

## Propósito del repositorio

Este repositorio es un laboratorio para aprender a usar Claude Code.
Los objetivos son:

* Practicar cómo dar instrucciones claras a Claude.
* Aprender a trabajar con agentes y, más adelante, con MCP.
* Mantener buenas prácticas de código, tests y documentación.

## Tecnologías preferidas

* Lenguaje: TypeScript (Node.js)
* Estilo de código: claro, explícito, fácil de leer.
* Estructura de carpetas simple y escalable (`src/`, `tests/`, etc.).

## Estilo de colaboración

Cuando trabajes en este repositorio:

1. **Explica primero, cambia después**
   Antes de aplicar cambios, explica qué piensas hacer y por qué.

2. **Pequeños pasos, cambios seguros**
   Prefiere cambios pequeños, bien explicados, antes que refactors gigantes de golpe.

3. **Respeta la intención del proyecto**
   Este es un laboratorio de aprendizaje. Prioriza código didáctico y comentado sobre optimizaciones extremas.

4. **Tests y ejemplos**
   Cuando crees funciones importantes, propone también:

   * ejemplos de uso
   * tests sugeridos (aunque no siempre los implementes todos)

## Qué puedes hacer

* Crear o actualizar archivos en `src/`.
* Proponer mejoras al README.
* Sugerir estructura de tests y carpetas.
* Más adelante, ayudar a crear y usar un MCP server sencillo.

## Qué evitar

* No añadir dependencias innecesarias.
* No hacer cambios masivos sin explicarlos primero.
* No asumir que este repositorio es de producción: es un espacio para aprender.
